# 資料結構學習診斷所

一個以資料結構學習成果檢驗為目標的學習診斷系統。

## 開發動機

受前人拋磚引玉，我在 GitHub 上的「CS 自學指南」獲益良多。如今我們能透過各種管道學習新知識，為了鞏固所學，會花時間重新翻閱教材、整理筆記，但學習一段時間後仍可能逐漸遺忘，需要再次複習。

這也讓我開始思考：**如何讓新知識成為長期記憶？又該如何檢驗自己的學習成果？**

「資料結構學習診斷所」便是從這個問題出發，將學習範圍聚焦於資料結構，透過不同形式的小測驗檢驗學習成果，找出需要加強的知識點，讓複習能更有方向、更有效率。

靈感來源：[CS 自學指南](https://github.com/pkuflyingpig/cs-self-learning)

## 目前版本

目前版本為 **MVP（Minimum Viable Product）**，以 **Binary Search** 作為第一個實作主題。

目前包含以下題型：

- Concept
- Trace
- Code
- Interactive
- Complexity

系統會根據使用者的作答內容進行基本評分，並回饋尚未掌握的核心觀念。

## 使用技術

- Python
- Flask
- HTML
- CSS
- Jinja
- JSON

## 專案狀態

目前已完成 Binary Search 學習診斷的基本流程與網頁介面。

此版本仍屬於 MVP，題目設計、評分方式與學習分析機制仍有進一步改善空間。
